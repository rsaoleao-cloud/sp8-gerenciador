⚙️ CONFIGURAÇÃO GITHUB

Configure uma vez — dados sincronizados em qualquer computador via GitHub Gist.

📖 Como criar o token (5 minutos, gratuito)
1 Acesse github.com e crie uma conta gratuita (ou faça login)
2 Clique na sua foto (canto superior direito) → Settings
3 No menu lateral, role até o fim → Developer settings → Personal access tokens → Tokens (classic)
4 Clique em Generate new token (classic) → dê um nome: SP8 Gerenciador → marque apenas gist → clique Generate token
5 Copie o token gerado (ghp_...) e cole abaixo
⚠️ Copie o token imediatamente — o GitHub só exibe uma vez. Se perder, gere outro.
Salvo só neste navegador. Nunca enviado a terceiros.
Após criar, copie este ID para usar em outros computadores.
